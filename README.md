## Python Programming Foundations

### 01. Python Setup
**File:** `01_python_setup_environment.py`

Verifies the Python development environment, displays Python version, operating system information, system architecture, and current date and time.

**Concepts:** Python Setup, Modules, System Information, Environment Verification.

### 02. Python Fundamentals – Variables & Data Types
**File:** `02_employee_management.py`

An Employee Information Management System that collects employee details, performs type casting, calculates annual salary, and displays employee information.

**Concepts:** Variables, Data Types, Input/Output, Type Casting, Comments, Data Type Checking.

### 03. Python Operators & Conditional Statements
**File:** `03_employee_performance_evaluation.py`

An Employee Performance Evaluation System that calculates performance scores, determines employee ratings, and checks bonus eligibility.

**Concepts:** Arithmetic Operators, Comparison Operators, Logical Operators, If-Else, Conditional Statements.

### 04. Python Loops & Iterations
**File:** `04_employee_salary_analysis.py`

An Employee Salary Analysis System that processes multiple employee records, calculates annual salaries, identifies high earners, and generates salary statistics.

**Concepts:** For Loops, While Loops, Iterations, Nested Data Structures, Accumulators.

### 05. Python Functions & Modular Programming
**File:** `05_employee_payroll_management.py`

An Employee Payroll Management System that uses reusable functions to calculate salaries, bonuses, tax deductions, and total payroll expenses.

**Concepts:** Functions, Arguments, Return Statements, Lambda Functions, Variable Scope, Modular Programming.

### 06. Python Data Structures
**File:** `06_employee_data_management.py`

An Employee Data Management System that stores, organizes, updates, and analyzes employee records using Python collections.

**Concepts:** Lists, Tuples, Sets, Dictionaries, Slicing, List Comprehensions.

### 07. Object-Oriented Programming (OOP)
**File:** `07_employee_management_oops.py`

An Employee Management System built using object-oriented programming principles to manage different employee roles and calculate bonuses.

**Concepts:** Classes, Objects, Constructors, Inheritance, Polymorphism, Encapsulation, Method Overriding.

### 08. Exception Handling & File I/O
**File:** `08_employee_file_management.py`

An Employee File Management System that validates employee records, handles exceptions, and reads and writes employee information using CSV and text files.

**Concepts:** Try-Except-Finally, Custom Exceptions, File Handling, CSV, Text Files, OS Module.

### 09. Working with APIs & JSON
**File:** `09_api_json_data_extraction.py`

A Python API Data Extraction program that consumes REST APIs, retrieves JSON responses, processes structured information, and saves API data into JSON files.

**Concepts:** REST APIs, HTTP GET Requests, Requests Library, JSON Parsing, Exception Handling.

### 10. Version Control with Git & GitHub
**File:** `10_git_github_workflow.py`

A practical demonstration of Git commands and version control operations for managing Python projects and collaborative development workflows.

**Concepts:** Git, GitHub, Repository Initialization, Staging, Commits, Branching, Merging, Remote Repositories.

### 11. Python Project – Mini Automation Tool
**File:** `11_automated_file_organizer.py`

An Automated File Organizer that identifies file extensions, creates categorized folders, moves files, handles duplicate filenames, and generates an execution summary.

**Concepts:** Python Automation, OS Module, Shutil Module, File Handling, Functions, Exception Handling.

## How to Run the Programs

**Step 1:** Clone the repository.

```bash
git clone <your-github-repository-url>
```

**Step 2:** Navigate to the project directory.

```bash
cd python-learning-journey
```

**Step 3:** Run any Python program.

```bash
python 01_Python_Foundations/02_employee_management.py
```

**Step 4:** For the API program, install Requests.

```bash
pip install requests
```
